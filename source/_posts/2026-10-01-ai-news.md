各位好，以下是今日值得关注的 AI 前沿动态。我们过滤了噪音，只保留对技术演进和产品落地有实质推动作用的几条信号。

## 1. DeepSeek 发布 V3 系列新模型，代码能力对标 Claude 3.5 Sonnet

DeepSeek 今日上线 DeepSeek-V3 的最新迭代版本，在 LiveCodeBench 等代码评测集上得分追平 Claude 3.5 Sonnet，推理成本仍维持在极低水平。模型权重同步在 Hugging Face 开源，采用 MoE 架构，激活参数约 37B。**影响分析**：这是国产开源模型首次在代码这一核心场景上对标闭源第一梯队，且推理定价仅为对手的几十分之一，对依赖代码生成能力的 AI 编程工具（Cursor、Windsurf 等）的底层选型构成直接冲击。开源权重意味着中小团队可以低成本私有化部署一个接近顶级水平的代码模型。

## 2. Anthropic 推出 Claude 的“计算机使用”能力，可直接操控桌面

Anthropic 发布 Computer Use 功能，Claude 3.5 Sonnet 可通过截图理解屏幕内容，并模拟鼠标点击、键盘输入来操作计算机。同步开放 API，开发者可构建自动化 Agent。**影响分析**：这是继 function calling 之后，Agent 能力的一次质变——从“调用 API”升级为“操控 GUI”。这意味着大量没有开放 API 的传统软件，理论上都能被 AI Agent 接管。短期内 RPA 行业将面临重构压力，长期看这是通向通用数字助手的关键一步。安全边界问题（模型误操作、提示注入攻击）也随之放大，值得持续关注。

## 3. Meta 开源 SAM 2：可分割视频中任意对象，支持实时追踪

Meta 发布 Segment Anything Model 2（SAM 2），将图像分割能力扩展到视频领域，支持对视频中任意对象进行分割与跨帧追踪，并保持实时推理速度。模型与数据集均以 Apache 2.0 协议开源。**影响分析**：SAM 1 已经重塑了图像标注和分割的工作流，SAM 2 把同样的能力带到视频，直接影响视频编辑、自动驾驶感知、医学影像分析等领域。开源协议宽松，预计很快会出现大量基于 SAM 2 的下游工具。视频数据标注的成本有望大幅下降，这对训练视频生成模型和多模态模型是间接利好。

## 4. OpenAI 发布 Realtime API，语音对话延迟降至接近人类水平

OpenAI 在开发者日推出 Realtime API，基于 WebSocket 实现语音到语音的直接交互，省去传统的“语音转文字→LLM→文字转语音”三段式管线，端到端延迟大幅降低。支持函数调用和多轮对话中的打断处理。**影响分析**：语音交互一直是 AI 产品体验的短板，三段式管线的延迟和情感丢失问题长期无解。Realtime API 把这个问题从架构层面解决了。客服、语音助手、语言学习、陪伴类产品的体验天花板被显著抬高。代价是成本——目前定价对高频语音场景仍偏高，但考虑到 OpenAI 一贯的降价节奏，这只是时间问题。
