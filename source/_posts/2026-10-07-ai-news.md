## 1. DeepSeek 开源 DeepGEMM：为 MoE 模型量身定制的 FP8 矩阵计算库

DeepSeek 今日正式开源了 DeepGEMM，一个专为密集型和 MoE（混合专家）模型设计的 FP8 通用矩阵乘法（GEMM）库。其核心亮点在于：在 Hopper 架构 GPU 上实现了超过 1350 TFLOPS 的 FP8 计算性能，且核心内核代码仅约 300 行，通过轻量级 JIT 编译实现运行时最优配置，无需预编译大量模板。

**影响分析**：这是对当前 MoE 大模型训练与推理基础设施的一次精准补强。FP8 训练已成为下一代大模型降本增效的关键路径，而 DeepGEMM 直接开源高性能实现，意味着中小团队也能在 Hopper 集群上以更低成本复现接近 DeepSeek-V3 级别的训练效率。代码极简、无重依赖的设计思路，也降低了社区二次开发的门槛。

## 2. Anthropic 发布 Claude 3.7 Sonnet：首个“混合推理”模型，API 可控制思考预算

Anthropic 今日推出 Claude 3.7 Sonnet，将其定位为“首个混合推理模型”——同一模型同时支持标准模式与扩展思考模式，用户可通过 API 参数精确控制模型在回答前进行多少“思考”（token 预算）。在编码与前端开发基准上，扩展思考模式刷新了 SOTA，且标准模式本身也优于前代 Claude 3.5 Sonnet。

**影响分析**：这标志着头部模型厂商开始将“推理时计算”的控制权交给开发者。与 OpenAI o1/o3 系列将推理过程黑盒化不同，Anthropic 选择让开发者按场景调节推理深度与成本，这对 Agent 工作流、复杂代码生成等需要精细控制延迟与质量的场景尤为关键。混合推理架构也可能成为下一代模型的标配范式。

## 3. 微软开源 Phi-4 多模态与 Phi-4-mini：小模型能力边界再推一步

微软今日开源了 Phi-4-multimodal（56 亿参数）和 Phi-4-mini（38 亿参数）。其中 Phi-4-multimodal 是微软首个多模态小模型，统一处理文本、图像和语音输入，在多项多模态基准上超越更大规模的专用模型；Phi-4-mini 则在文本推理与函数调用能力上显著领先同尺寸模型。

**影响分析**：小模型赛道的竞争已从“文本能力压缩”进入“多模态统一架构”阶段。Phi-4-multimodal 以不到 6B 的参数实现三模态输入，意味着端侧和边缘设备上的多模态 Agent 部署门槛大幅降低。对开发者而言，这提供了 GPT-4o 级别多模态能力的轻量级替代方案，尤其适合隐私敏感或离线场景。

## 4. 阿里通义万相 2.1 开源：视频生成模型首次实现中文文字渲染

阿里今日开源通义万相 2.1 视频生成模型，包含 14B 和 1.3B 两个版本。核心突破在于：首次在开源视频生成模型中实现中文字符的稳定渲染，同时支持复杂运动轨迹控制与物理规律模拟。1.3B 版本可在消费级显卡上运行，14B 版本在 VBench 榜单上得分领先。

**影响分析**：视频生成的开源竞争正在从“画面质量”转向“可控性与可用性”。中文文字渲染的突破直接解锁了广告、短视频、电商素材等大量商业场景——此前这些场景因无法生成可读文字而难以落地。1.3B 版本的低部署门槛，也可能催生一批本地化视频生成工具链。
