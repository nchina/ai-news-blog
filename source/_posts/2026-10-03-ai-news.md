今日值得关注的动态集中在模型推理效率、开源生态与 Agent 基础设施三个方向，以下为精选条目。

## 1. DeepSeek 开源 DeepGEMM：FP8 矩阵乘法库，Hopper 架构上突破算力瓶颈

DeepSeek 今日开源了 DeepGEMM，一个专为 FP8 通用矩阵乘法（GEMM）设计的高性能 CUDA 库。其核心亮点在于：在 NVIDIA Hopper GPU 上实现了超过 1350 TFLOPS 的 FP8 算力，且代码库极简——核心内核仅约 300 行，同时支持稠密计算和 MoE（混合专家）模型的分组 GEMM。该库已在 DeepSeek-V3 的训练中得到验证。**影响分析**：FP8 训练与推理的工程门槛被进一步拉低，中小团队可直接复用经过大规模验证的高性能内核，MoE 架构的部署成本有望显著下降。

## 2. Anthropic 发布 Claude 3.7 Sonnet 与 Claude Code：首个“混合推理”模型正式落地

Anthropic 推出 Claude 3.7 Sonnet，定位为首个“混合推理”模型——用户可在标准模式与扩展思考模式之间切换，同一模型同时覆盖快速响应和深度推理场景。同步发布的 Claude Code 是一款终端内的 Agent 编程工具，支持代码库理解、文件编辑、测试运行与提交管理。**影响分析**：混合推理架构意味着推理成本可按任务复杂度动态分配，这对企业级 API 调用场景的性价比优化具有直接意义；Claude Code 则标志着 Anthropic 正式进入 Agent 编程工具赛道，与 Cursor、Windsurf 等形成正面竞争。

## 3. Google 开源 Gemma 3：单 GPU 可跑的多模态模型系列

Google 发布 Gemma 3 系列开源模型，覆盖 1B、4B、12B、27B 四个参数规模，其中 27B 版本声称在单张 NVIDIA H100 或 TPU 上即可运行。该系列原生支持多模态输入（文本+图像），提供 128K 上下文窗口，并覆盖 140 种语言。**影响分析**：Gemma 3 的定位明确——在消费级/单卡硬件上提供可用的多模态能力。这对于边缘部署、隐私敏感场景和学术研究是实质性利好，也进一步压缩了“小参数模型不能做多模态”的固有认知。

## 4. Cursor 发布 Claude 3.7 集成与 Agent 模式更新

AI 编程编辑器 Cursor 在 Claude 3.7 Sonnet 发布后数小时内完成集成，并同步更新了其 Agent 模式：支持更长的多步任务链、更准确的代码库索引，以及在前台/后台任务间切换的能力。**影响分析**：模型发布到工具链集成的延迟已缩短至小时级，AI 编程工具的竞争焦点正从“用哪个模型”转向“Agent 编排质量与上下文管理能力”。对开发者而言，工具切换成本持续降低，实际生产力差异将更多取决于工作流设计而非模型选择。
