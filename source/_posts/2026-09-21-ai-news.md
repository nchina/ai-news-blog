今日值得关注的动态集中在模型能力边界突破与智能体基础设施两个方向：一边是多模态推理与长程任务规划能力被推进到新阶段，另一边是围绕 Agent 的协议、运行时与评测体系开始快速补齐。以下 4 条是本日最具决定性意义的变化。

## 1. OpenAI 发布 o3 与 o4-mini：把图像纳入思维链，并首次系统化调用工具

- o3 / o4-mini 在推理过程中可原生调用 Python、网页搜索、图像分析等工具，并把这些调用结果直接纳入推理链，而非事后拼接。
- 图像理解被整合进“思考”环节，模型能对图表、草图、代码截图进行多步推理，视觉不再只是输入模态而是推理素材。
- 影响：推理模型与 Agent 的边界进一步模糊，工具调用从“外挂”变成模型内部决策的一部分，对 Agent 框架和评测基准提出新要求。

## 2. Google 发布 Gemini 2.5 Flash：面向高吞吐 Agent 的推理可控模型

- 引入“思考预算”机制，开发者可按任务复杂度动态控制推理 token 消耗，在延迟、成本与准确率之间做显式权衡。
- 定位明确指向大规模 Agent 工作流与实时应用，强调单位成本下的推理效率而非单纯刷榜。
- 影响：推理成本可编程化，意味着 Agent 系统可以按任务分级调度算力，这对生产级部署比单纯提升 benchmark 更关键。

## 3. Anthropic 推出 Claude Research 与 Google Workspace 集成：长程研究型 Agent 落地

- Claude 可在多轮搜索、阅读、交叉验证后产出带引用的研究报告，单次任务可自主运行较长时间。
- 与 Gmail、Calendar、Docs 的集成让 Agent 直接进入真实工作流，读写企业数据并执行操作。
- 影响：Agent 竞争从“能不能做”转向“能不能在真实数据与权限体系里可靠地做完”，企业级权限、审计与可追溯性成为下一阶段核心。

## 4. 开源侧：Llama 4 系列与多个 Agent 协议/运行时集中更新

- Llama 4 Scout / Maverick 采用 MoE 架构并支持超长上下文，继续压低开源多模态与长上下文能力的门槛。
- MCP、A2A 等 Agent 互操作协议持续被主流工具链采纳，开源运行时与评测框架同步补齐。
- 影响：模型层能力差距在缩小，竞争重心向协议、工具生态与运行时可靠性转移，开源 Agent 基础设施进入快速收敛期。

整体看，今天的主线不是单点模型刷分，而是推理、工具调用与真实工作流三者的耦合在加速。接下来值得盯的是：推理成本可控化之后，Agent 的可靠性与权限治理能否跟上。
