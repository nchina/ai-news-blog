今日值得关注的动态集中在开源模型能力跃迁、推理基础设施重构与智能体协议标准化三条主线，以下为精选条目。

## 1. DeepSeek 开源 V3.2-Exp，稀疏注意力将长上下文推理成本压至新低

DeepSeek 发布并开源 V3.2-Exp 实验版本，核心是自研的稀疏注意力机制（DSA），在几乎不损失基准性能的前提下大幅降低长序列推理的算力开销，API 价格同步下调 50% 以上。配套论文与权重均已公开，可复现性高。其意义在于：长上下文的经济性瓶颈正从“模型能力”转向“系统工程”，稀疏化路线对现有稠密注意力架构构成直接替代压力，推理侧的降本竞赛将进一步加速。

## 2. 智谱 GLM-4.6 发布，国产开源模型首次在编码智能体场景对标闭源旗舰

GLM-4.6 面向 Coding Agent 场景优化，上下文窗口扩展至 200K，在真实工程任务与工具调用链上的表现接近 Claude Sonnet 4 级别，并同步开源权重、适配主流国产芯片推理。要点有二：一是开源模型的能力边界已从“通用对话”推进到“可落地的工程智能体”；二是软硬件协同适配正在成为国产模型差异化竞争的实际抓手，而非单纯的参数竞赛。

## 3. Anthropic 开源 Agent Skills 规范，智能体能力封装走向标准化

Anthropic 将 Agent Skills 以开放规范形式发布，用“技能包”（指令、脚本与资源的组合）统一智能体可复用能力的描述与调用方式，并推动其成为跨模型、跨平台的通用约定。这解决的是智能体生态中长期存在的碎片化问题——能力无法迁移、复现与审计。若被主流框架采纳，智能体开发将从“每次重写提示词与工具链”转向“技能注册与组合”，工程效率与可维护性会有量级提升。

## 4. vLLM 发布生产级 RL 训练框架，推理引擎反向切入后训练环节

vLLM 推出面向生产环境的强化学习训练框架，将高吞吐推理能力直接复用于 RL 采样与 rollout 阶段，缓解后训练中采样吞吐与显存调度的核心瓶颈。这一动向的信号意义明确：推理基础设施与训练基础设施的边界正在消融，RL 后训练从“研究脚本”走向“可运维的生产流水线”，将显著降低推理模型迭代的工程门槛。

## 5. OpenAI 推出 AgentKit 与 Apps SDK，智能体开发进入平台化阶段

OpenAI 发布 AgentKit 工具集（含可视化编排、评测与连接器）及 Apps SDK，允许第三方应用以结构化方式接入其智能体运行时。核心影响在于分发层：智能体的入口正从“独立应用”转向“嵌入既有工作流”，平台方通过 SDK 锁定开发者生态，与前述开源协议形成标准之争。对开发者而言，跨平台可移植性将成为下一阶段的关键选型指标。
