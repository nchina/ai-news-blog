今日值得关注的动态集中在模型能力边界突破、开源生态演进与端侧部署三个方向，以下为精选内容。

## 1. Anthropic 发布 Claude 4.5，长上下文推理与代码能力同步跃升

Anthropic 今日正式推出 Claude 4.5，核心升级集中在 200K 上下文窗口内的多步推理一致性与代码生成准确率。在 SWE-bench Verified 上得分较上一代提升约 8 个百分点，同时在长文档问答中显著降低了“中间遗忘”现象。该版本已通过 API 与 Claude.ai 同步上线，企业级用户可直接切换。对行业而言，这意味着头部模型在“可用性”维度上的竞争已从单纯刷榜转向真实工作流中的可靠性，Agent 类产品的底层推理成本与错误率有望进一步下降。

## 2. Meta 开源 Llama 4 系列首个 MoE 架构模型，推理成本大幅下降

Meta 今日在 Hugging Face 上发布了 Llama 4 Scout 与 Llama 4 Maverick 两个开源权重模型，均采用混合专家（MoE）架构。其中 Scout 拥有 17B 激活参数、16 个专家，支持 10M token 上下文窗口，可在单张 H100 上运行。这是 Meta 首次将 MoE 引入 Llama 系列，且附带完整模型卡与评测数据。对开源社区而言，超长上下文与低推理成本的组合将直接推动本地 RAG、代码库级理解等场景的落地，同时给闭源 API 定价带来持续压力。

## 3. Google 推出端侧多模态模型 Gemma 3n，可在手机内存中运行

Google 今日发布 Gemma 3n，专为边缘设备设计，采用 Per-Layer Embedding 与条件参数加载技术，使模型在 2GB 内存以下即可运行多模态推理（文本、图像、音频）。该模型已在 Kaggle 和 Hugging Face 上开放权重，并针对 Android 的 AICore 做了适配。其核心价值在于将多模态能力从云端下沉到终端，为隐私敏感场景（如本地相册理解、离线语音助手）提供了可用的开源方案，也进一步加剧了端侧 AI 框架的竞争。

## 4. 英伟达发布 Cosmos-Reason1，面向物理推理的世界模型

英伟达今日公开了 Cosmos-Reason1 系列，定位为“物理常识推理”世界模型，包含 7B 与 34B 两个版本，训练数据涵盖视频、机器人轨迹与合成物理场景。该模型在物理因果推断、空间关系理解等基准上显著优于通用多模态模型，并已开源推理代码。其意义在于为机器人、自动驾驶与具身智能提供了专门的基础模型层，可能改变当前“用通用 VLM 硬套物理任务”的工程范式，加速仿真到现实的迁移效率。
