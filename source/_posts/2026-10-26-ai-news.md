今日值得关注的动态集中在模型能力边界突破、推理成本重构与开源生态演进三个方向，以下精选四条具备实质技术含量或产业杠杆效应的进展。

## 1. DeepSeek 发布 V3 模型并开源权重

DeepSeek 正式上线 V3 系列模型，采用 MoE 架构，总参数量 671B、激活参数 37B，训练成本约 558 万美元，并同步开源模型权重与技术报告。核心影响在于：以显著低于行业预期的算力预算达到接近一线闭源模型的基准表现，直接压低了推理侧的单位成本预期，也让“高效训练 + 开放权重”成为可复现的工程范式，对中小团队自建能力构成实质利好。

## 2. OpenAI 推出 o3 推理模型，测试时计算成为新 scaling 轴

OpenAI 发布 o3（及 o3-mini），在 ARC-AGI、竞赛级数学等基准上大幅刷新纪录，其核心机制是在推理阶段投入更多“思考 token”进行搜索与验证。这一进展的意义不在于单一榜单，而在于确认了“测试时计算”作为独立于预训练规模的能力增长路径，将推动推理基础设施、验证器设计与成本调度成为下一阶段架构竞争的关键环节。

## 3. Google 发布 Gemini 2.0 Flash 并开放实时多模态 API

Google 推出 Gemini 2.0 Flash，支持原生多模态输入输出、实时音视频流处理与工具调用，并通过 API 向开发者开放。其技术价值在于将低延迟的实时多模态交互做成可编程接口，使语音代理、屏幕理解、实时翻译等应用从 demo 走向可部署产品，同时加剧了多模态推理的 API 价格与延迟竞争。

## 4. 开源推理框架密集迭代，vLLM/SGLang 强化结构化输出与投机解码

vLLM 与 SGLang 近期连续合并多项关键更新，涵盖更高效的前缀缓存复用、投机解码调度优化以及对约束解码（结构化输出）的深度支持。这类基础设施进展虽不显眼，却直接决定推理吞吐与单位 token 成本，是把模型能力转化为可规模化产品的底层杠杆，值得工程团队优先跟进版本升级。
