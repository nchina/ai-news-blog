今日值得关注的技术信号集中在模型能力边界、推理基础设施与开源生态三个方向，以下为筛选后的关键动态。

## 1. DeepSeek 发布 V3 模型并开源权重

DeepSeek 正式上线 V3 系列模型，采用 MoE 架构，总参数量 671B、激活参数 37B，训练成本约 558 万美元，同步开源模型权重与技术报告。核心影响在于：以显著低于行业预期的算力预算达到接近一线闭源模型的基准表现，直接压低了“前沿能力”的资本门槛，并推动 MoE + FP8 训练路线成为可复现的工程范式。对推理侧而言，其低成本 API 定价也在倒逼整个市场重新核算单位 token 经济性。

## 2. OpenAI 发布 o3 系列，推理时计算成为新 Scaling 轴

OpenAI 公布 o3 及其轻量版本，在 ARC-AGI、竞赛数学与代码基准上大幅刷新纪录，核心机制是在推理阶段投入更多思考 token 进行搜索与验证。这标志着 scaling 重心从“预训练参数”向“推理时计算”迁移：模型能力可以通过测试时算力弹性扩展，但也意味着推理成本与延迟成为产品设计的一等约束，对推理芯片、调度系统和缓存架构提出新的工程要求。

## 3. 谷歌发布 Gemini 2.0 Flash，主打原生多模态与 Agent 能力

Google 推出 Gemini 2.0 Flash，支持原生图像、音频输出与工具调用，并开放多模态实时 API，定位为 Agent 时代的基础模型。其意义在于把“多模态输入输出 + 函数调用 + 低延迟流式交互”打包为默认能力，降低了构建实时语音/视觉 Agent 的集成成本，也加剧了与 OpenAI 实时 API 在开发者生态上的正面竞争。

## 4. Meta 开源 Llama 3.3 70B，以中小尺寸对标大模型

Meta 发布 Llama 3.3 70B，官方称其性能接近 405B 版本，同时推理成本大幅下降，权重开放下载。这条动态的关键不在参数规模，而在于“蒸馏与训练配方”的成熟：用 70B 承载原先需要 400B+ 的能力，使单卡/少卡部署高质量模型成为现实，进一步压缩了中小团队自建推理服务的硬件门槛。

## 5. 英伟达发布 Cosmos 世界基础模型平台

NVIDIA 推出 Cosmos 世界基础模型系列，面向物理 AI 与自动驾驶场景，提供可生成符合物理规律合成数据的预训练模型，并配套开放训练与后训练工具链。其价值在于把“合成数据生成”从零散脚本升级为平台化基础设施，缓解机器人与自动驾驶领域真实数据稀缺的瓶颈，同时把仿真到现实的迁移能力纳入模型层竞争。

整体来看，今日动态的共同指向是：能力提升越来越依赖推理时计算与数据工程，而非单纯堆参数；开源权重与低成本训练配方持续侵蚀闭源模型的护城河；而多模态 Agent 与物理 AI 正在成为下一阶段基础设施竞争的主战场。
