今日值得关注的动态集中在模型能力边界突破与推理成本重构两条主线：一边是多模态与长上下文能力被推向新高度，另一边是开源生态用更激进的架构把推理成本继续压向极限。以下为精选内容。

## 1. DeepSeek 开源 V3.2-Exp，稀疏注意力把长文本推理成本砍到脚踝

DeepSeek 发布实验性版本 V3.2-Exp，核心是自研的 DeepSeek Sparse Attention（DSA）稀疏注意力机制，在保持长上下文能力的前提下大幅降低计算复杂度，官方同步下调 API 价格逾 50%。这是继 V3 之后对“注意力架构”的又一次直接改造，意义在于：长上下文不再是靠堆算力硬撑，而是从算子层面重构。对做 RAG、长文档处理与 Agent 记忆的团队而言，单位 token 成本与延迟的下降会直接改变产品可行性边界。

## 2. 阿里通义千问开源 Qwen3-Omni，端到端全模态统一架构落地

Qwen3-Omni 以开源形式发布，主打文本、图像、音频、视频的原生统一建模，而非多模型拼接，并在多个跨模态基准上对标闭源旗舰。其价值不在单项跑分，而在于“一个模型处理全模态输入输出”的工程范式——这直接降低了多模态应用的系统复杂度与调度开销。对开发者来说，可商用开源权重意味着全模态能力第一次能以可控成本进入自有部署。

## 3. 谷歌发布 Gemini 2.5 Computer Use，把“操作浏览器”做成模型原生能力

谷歌推出面向计算机操作的专用模型 Gemini 2.5 Computer Use，可理解屏幕并执行点击、输入、滚动等 GUI 操作，通过 API 向开发者开放。这是把 Computer-Use / GUI Agent 从“提示词工程+框架拼装”推进到“模型原生能力”的关键一步。对 RPA、自动化测试、网页任务代理类产品冲击直接：过去依赖脆弱选择器脚本的链路，正在被视觉理解+动作生成替代。

## 4. 英伟达开源 Nemotron-Nano-9B-v2，混合架构瞄准端侧推理

英伟达发布 Nemotron-Nano-9B-v2 并开源权重，采用 Mamba-Transformer 混合架构，强调在较小参数量下的推理效率与可控性（支持推理开关）。其信号意义大于单点性能：芯片厂商正用开源模型反向定义“硬件友好架构”，混合状态空间模型在长序列与端侧场景的成本优势开始被主流厂商背书。对边缘部署与私有化推理的团队，这是一条值得纳入评测的新基线。

## 5. 智谱开源 GLM-4.6，代码与 Agent 能力对标闭源一线

智谱发布并开源 GLM-4.6，重点提升代码生成、工具调用与长程 Agent 任务表现，上下文窗口进一步扩展，并在多项编程基准上对标国际闭源模型。国产开源模型在“代码+Agent”这一最高价值场景持续逼近闭源，意味着企业构建编码助手与自动化工作流的模型选型空间被实质拓宽，迁移成本与锁定风险同步下降。

整体看，今天的共性趋势清晰：架构级创新（稀疏注意力、混合 SSM、全模态统一）正在替代单纯的参数扩张，成为压低成本、拓展能力边界的主要杠杆；而 Computer-Use 与代码 Agent 则是最接近规模化落地的两个方向。
