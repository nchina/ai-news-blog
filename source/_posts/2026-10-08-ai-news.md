各位好，以下是今日值得关注的技术动态。我们过滤了噪音，只保留对架构、开源生态和产品落地有实质影响的几条。

## 1. 谷歌发布 Gemini 1.5 Pro 重大更新，开放 200 万 token 上下文窗口

谷歌今日将 Gemini 1.5 Pro 的上下文窗口从 100 万扩展至 200 万 token，并通过 AI Studio 和 Vertex AI 向开发者开放。这意味着单次可处理约 150 万英文单词——相当于 2 小时视频、22 小时音频或超过 6 万行代码。核心突破在于其近乎完美的“大海捞针”检索能力，在 200 万 token 长度下仍保持 >99% 的召回率。对行业而言，这直接冲击了 RAG（检索增强生成）的现有架构：当模型原生支持如此长的上下文时，大量依赖向量数据库分块检索的场景可能需要重新评估技术栈。

## 2. Meta 开源 Llama 3 系列模型权重，同步发布 80 亿与 700 亿参数版本

Meta 正式开源 Llama 3，首批包含 8B 和 70B 两个规格，均支持 8K 上下文，并采用新的 tokenizer（词汇量 128K），在 MMLU、HumanEval 等基准上同尺寸下表现领先。模型权重已在 Hugging Face 开放下载，且附带完整的训练数据截止说明与安全微调版本。这是目前开源社区最强的基座模型之一，尤其 8B 版本可在消费级显卡上运行，预计将催生大量本地化部署与垂直微调项目。对闭源 API 厂商而言，开源模型性能逼近 GPT-3.5 水平，价格压力进一步加大。

## 3. 微软发布 Phi-3-mini：38 亿参数模型性能超越 Mixtral 8x7B

微软研究院推出 Phi-3 系列首个模型 Phi-3-mini，参数量仅 3.8B，却在 MMLU（69%）、MT-Bench（8.38）等基准上大幅超越同尺寸模型，甚至逼近 Mixtral 8x7B 和 GPT-3.5。该模型已在 Hugging Face 开源，支持 4K 和 128K 两种上下文版本，可在手机端本地运行。核心创新在于训练数据的“教科书级”筛选策略——用高质量、高密度的合成数据替代海量爬取数据。这验证了一条重要路径：小模型 + 极致数据工程，可以在推理成本极低的前提下达到可用的通用能力，对边缘 AI 和端侧 Agent 意义重大。

## 4. Stability AI 发布 Stable Diffusion 3 API，并开源 8 亿参数文本编码器

Stability AI 今日开放 SD3 的 API 访问，同时开源了其三个文本编码器中的两个（CLIP L 和 OpenCLIP bigG），合计 8 亿参数。SD3 采用全新的 MMDiT（多模态扩散 Transformer）架构，在文字渲染、手部细节和多主体组合提示上显著优于 SDXL。 API 定价为每张图 0.01 美元起。开源文本编码器意味着社区可以更深入地研究 MMDiT 的条件控制机制，并可能加速基于 SD3 架构的微调与蒸馏工作。对图像生成赛道而言，SD3 的架构方向（用 Transformer 替代 U-Net）正在成为新的共识。

## 5. 英伟达发布 CUDA 12.4，原生支持 FP8 与动态并行

英伟达在 GTC 后续更新中推出 CUDA 12.4，重点包括：对 Hopper 架构 FP8 精度的原生库支持、动态并行（Dynamic Parallelism）的性能优化，以及针对 LLM 推理的 kernel 自动调优工具。FP8 原生支持意味着在 H100 上运行大模型推理时，可在几乎不损失精度的情况下将吞吐量提升近一倍。动态并行的改进则让递归神经网络和自适应计算图在 GPU 上的调度开销大幅降低。对推理服务商和训练框架开发者来说，升级到 CUDA 12.4 是释放 Hopper 全部算力的必要步骤。
