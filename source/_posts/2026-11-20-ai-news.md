今日值得关注的技术信号集中在模型推理效率、开源权重与智能体基础设施三个方向，以下为精选条目。

## 1. DeepSeek 开源 V3.2-Exp，稀疏注意力将长上下文推理成本压至新低

DeepSeek 发布实验性版本 V3.2-Exp，核心是自研的 DeepSeek Sparse Attention（DSA）稀疏注意力机制，在保持长文本能力的前提下大幅降低推理算力消耗，并同步下调 API 价格。模型权重已在 Hugging Face 开放，技术报告同步公开。这是继 V3 之后又一次以架构级创新直接冲击单位 token 成本的动作，对长上下文应用的商业化门槛有实质性下压作用。

## 2. 智谱开源 GLM-4.6，编码与智能体能力对标闭源第一梯队

智谱发布并开源 GLM-4.6，重点提升代码生成、工具调用与多步智能体任务表现，上下文窗口扩展至 200K，并适配国产芯片推理。权重与推理代码同步开放。在开源权重模型普遍追赶闭源旗舰的当下，这一版本把“可私有化部署的编码/Agent 基座”推到了更接近生产可用的水平，对企业级落地选型影响直接。

## 3. Anthropic 发布 Claude Sonnet 4.5，主打长时程自主编码与计算机操作

Anthropic 推出 Claude Sonnet 4.5，官方定位为“全球最强编码模型”，在 SWE-bench 等真实软件工程基准上刷新成绩，并强化了连续数十步自主操作计算机、跨工具完成复杂任务的能力，同时开放 Claude Agent SDK。信号意义在于：竞争焦点正从单轮 benchmark 分数转向“长时程任务可靠性”与智能体开发生态，这会重新定义模型评测与产品形态。

## 4. 阿里通义开源 Qwen3-Omni，端到端全模态统一架构落地

通义千问团队开源 Qwen3-Omni，采用端到端多模态统一架构，原生支持文本、图像、音频、视频的输入与实时语音输出，无需外挂拼接式模块。权重与推理框架均已开放。全模态端到端路线此前多停留在论文与闭源演示阶段，此次开源为实时语音交互、多模态 Agent 等场景提供了可直接二次开发的基座，是架构层面的实质性推进。

## 5. OpenAI 推出 AgentKit，把智能体开发收敛为标准工程链路

OpenAI 发布 AgentKit，包含可视化 Agent Builder、统一连接器注册表与评测优化工具集，将智能体从原型到上线的流程标准化。这标志着头部厂商开始把“Agent 开发”当作平台级基础设施来经营，而非零散 API 能力；对中小团队而言降低了工程门槛，但也意味着智能体中间层创业公司的差异化空间被进一步压缩。
