## 1. DeepSeek 开源 DeepGEMM：为 MoE 模型打造的高性能 FP8 矩阵计算库

DeepSeek 今日正式开源了 DeepGEMM，这是一个专为混合专家（MoE）模型设计的高性能 FP8 通用矩阵乘法（GEMM）库。其核心亮点在于：仅用约 300 行代码，就在 Hopper 架构 GPU 上实现了超越专家调优库（如 cutlass）的 FP8 计算性能，并原生支持 MoE 分组 GEMM 与普通 GEMM。该库采用即时编译（JIT）方式，部署时无需预编译，极大降低了 FP8 训练与推理的工程门槛。**影响分析**：这是继 DeepSeek-V3 技术报告后，对“FP8 训练稳定性与效率”的又一次工程级验证。它把 MoE 模型最核心的矩阵计算瓶颈做了极致优化，且完全开源，意味着更多团队可以低成本复现高效 MoE 训练，可能加速 FP8 在开源大模型中的普及。

## 2. Anthropic 发布 Claude 3.7 Sonnet：首个“混合推理”模型，API 可控制思考预算

Anthropic 今日推出 Claude 3.7 Sonnet，最大特点是同时具备“标准模式”与“扩展思考模式”，用户可通过 API 设定模型思考的 token 预算，在速度与深度推理之间灵活切换。在编码、数学、指令遵循等基准上，其扩展思考模式刷新了 SOTA，且模型本身在标准模式下也比前代更强。**影响分析**：这标志着头部模型开始把“推理时计算”做成可编程接口，而非固定开关。对开发者而言，意味着可以按任务复杂度动态分配算力成本，这对 Agent 工作流和复杂代码生成场景有直接落地价值。

## 3. 微软开源 Phi-4-multimodal 与 Phi-4-mini：小模型也能处理语音、视觉与文本

微软今日开源了 Phi-4 系列的两个新成员：Phi-4-multimodal（多模态）和 Phi-4-mini（纯文本）。前者是微软首个统一处理语音、视觉和文本的多模态小模型，后者则在同尺寸级别中文本推理能力突出。两者均可在边缘设备或低算力环境运行，且已上传至 Hugging Face。**影响分析**：小模型赛道正从“拼参数”转向“拼多模态统一与端侧部署”。Phi-4-multimodal 的开源，让端侧设备同时理解语音和图像成为可能，对隐私敏感场景和离线 Agent 是重要基建。

## 4. 阿里通义千问开源 QwQ-32B：推理能力接近 R1，但参数仅 1/20

阿里 Qwen 团队今日开源了 QwQ-32B 推理模型。根据官方评测，其在数学、代码和通用推理任务上的表现，与 DeepSeek-R1（671B）相当，但参数量仅为后者的约 1/20，且支持消费级显卡部署。模型权重已以 Apache 2.0 协议开放。**影响分析**：这是“小参数高推理”路线的又一次强力证明。如果 QwQ-32B 的实际表现与评测一致，意味着高质量推理能力可以下放到单张 24G 显存卡，对学术研究和中小团队自建推理服务是重大利好。

## 5. 谷歌发布 Gemma 3：单 GPU/TPU 可跑的多模态开源模型家族

谷歌今日推出 Gemma 3 系列开源模型，涵盖 1B、4B、12B、27B 等多个尺寸，均支持 128K 上下文和多模态输入（视觉+文本）。其中 27B 版本在单张 GPU 或 TPU 上即可运行，官方称其为“同等规模下最强开源模型”。**影响分析**：谷歌明显在加快开源节奏，Gemma 3 的多尺寸+多模态组合，直接对标 Llama 和 Qwen 的生态位。尤其 27B 单卡可跑，对想私有化部署多模态能力的团队很有吸引力。
